# ТЗ для программиста: обновление слэш-команд бота @Napominaskhabot

## Что нужно сделать

1. **Заменить** набор слэш-команд и тексты шаблонов на актуальные из `commands.json` (по одному элементу на шаг воронки; у команд с вариантами по пакету несколько элементов с одним `command`).
2. **Удалить** старые команды, которых нет в актуальном списке (ниже).
3. К командам, где указан `image`, бот должен отправлять картинку из `media/images/`, текст идёт подписью или следующим сообщением. К `/видео_кабинет` относится видео `media/videos/video_lk_instrukciya.mp4`.
4. Плейсхолдеры в `{ФИГУРНЫХ_СКОБКАХ}` бот **не подставляет**: менеджер правит текст вручную и сам отправляет клиенту (бот клиенту ничего не пишет). Список плейсхолдеров по каждой команде есть в `commands.json` (`placeholders`).
5. Бот выдаёт шаблон **менеджеру** (как и раньше), клиенту сообщения не рассылает.
6. Меню Telegram (`/setcommands` у BotFather) принимает только латиницу, цифры и `_`. Кириллические команды в меню не появятся: если бот сейчас принимает их текстом, продолжайте так же.

## Структура репозитория

- `commands.json`: все команды, тексты, подсказки менеджеру, пути к медиа, плейсхолдеры.
- `commands.txt`: те же тексты в читаемом виде.
- `media/images/`: картинки к командам.
- `media/videos/`: видео к `/видео_кабинет`.

## Подсказка менеджеру

Поле `manager_hint` в `commands.json` — пояснение для менеджера (когда отправлять, что подставить). Его желательно показывать менеджеру вместе с шаблоном, клиенту оно не уходит.
